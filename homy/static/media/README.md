# Medien-Ordner (optional)

Dateien in `homy/static/media/` werden direkt unter `/static/media/` ausgeliefert.

**Empfohlen:** Icons und Hintergründe über die Upload-Funktion in Einstellungen oder Admin hochladen — dann sind Berechtigungen (global / nur für mich) sauber geregelt.

Hier abgelegte Dateien eignen sich für fest eingebaute Standard-Icons im Repository.
